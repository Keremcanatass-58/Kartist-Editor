Vizeden Finale: Ne Değişti?

Vize sürümü (v2.0) bir bireysel tasarım aracıydı. Final sürümü (v3.0) ise bir topluluk platformudur. Kullanıcılar artık tasarımlarını paylaşır, birbirini takip eder, gerçek zamanlı yayın açar, düello ve yarışmalara katılır; sistem onları XP ve rozetlerle ödüllendirir. Bu dönüşüm, dersin odağı olan sistem analizi ve tasarımı sürecinin tüm aşamalarını — gereksinim analizi, katmanlı (N-tier) mimari tasarımı, veri (ER) modelleme ve süreçlerin UML/sequence diyagramlarıyla modellenmesi — gerçek bir ürün üzerinde uygulamaya geçirme fırsatı sundu.

Tamamlandı

  • SQL INJECTION ÖNLEME Tüm sorgular @param ile parametrik; string birleştirme yasak.

SecurityHeadersMiddleware.cs

// Her HTTP yanıtına güvenlik başlıkları ekleyen middleware public async Task InvokeAsync(HttpContext context) { context.Response.Headers.Append("X-Frame-Options", "SAMEORIGIN"); context.Response.Headers.Append("X-Content-Type-Options", "nosniff"); context.Response.Headers.Append("Referrer-Policy", "strict-origin-when-cross-origin"); // Content-Security-Policy: kaynak (script/style/connect) kısıtları context.Response.Headers.Append("Content-Security-Policy", csp); context.Response.Headers.Remove("Server"); // parmak izi gizle await _next(context); }
Ağ/Güvenlik Notu: CSP, tarayıcıya hangi kaynaktan script/stil/bağlantı yükleyebileceğini bildiren bir HTTP yanıt başlığıdır ve XSS saldırılarını sınırlar. Statik yollar (/lib/, /css/, /uploads/) ve OAuth callback'leri başlıktan muaf tutulur.
